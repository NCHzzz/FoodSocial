# Delivery Archive

Use this folder for superseded, completed, cancelled, or otherwise inactive delivery artifacts.

## Purpose

The archive keeps active delivery folders readable while preserving useful historical specs and plans.

## Rules

- keep active specs in `docs/delivery/specs/`
- keep active plans in `docs/delivery/plans/`
- move inactive artifacts here when they still have reference value
- delete duplicate or worthless drafts instead of archiving them

## Recommended structure

- `docs/delivery/archive/specs/`
- `docs/delivery/archive/plans/`

If these subfolders do not exist yet, create them when the first archived artifact is moved.
