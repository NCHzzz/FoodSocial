# Search First

## When to Use

- feature work touching multiple modules
- unclear requests
- architecture-sensitive tasks
- changes affecting APIs, flows, recommendation, moderation, or auth

## Workflow

1. Read `AGENTS.md`
2. Read `docs/ai/repo-map.md`
3. Read only the relevant files in `docs/project-discovery/`
4. Identify architecture and product constraints
5. Only then propose or implement changes

## Expected Outcome

- minimal ambiguity
- fewer incorrect assumptions
- better alignment to the approved MVP shape
