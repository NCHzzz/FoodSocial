# Frontend

Starter scaffold for an Angular app-shell structure.

## Layout

- `src/app/core/` singleton services, guards, app-wide providers, and bootstrap concerns.
- `src/app/shared/` reusable UI primitives, models, pipes, and utilities.
- `src/app/features/` feature-focused screens and flows.
- `src/app/app.routes.ts` placeholder for root route definitions.
- `src/app/app.config.ts` placeholder for Angular app configuration.
- `src/app/app.component.ts` placeholder for the root shell component.
- `src/assets/` static assets.
- `src/environments/` environment placeholders.
- `docs/` frontend notes and UI conventions.
- `tests/` frontend test organization placeholders.

This scaffold is intentionally non-runnable and only establishes a clear starting layout.
